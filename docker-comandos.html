Tutorial: Primer contenedor web

Paso a paso para crear y desplegar el contenedor

  1. Crear una carpeta de trabajo, por ejemplo: C:\docker-lab-web.

  2. Dentro de esa carpeta, crear un archivo index.html.

  3. En la misma carpeta, crear un archivo llamado Dockerfile (sin extensión) con la configuración para Nginx.

  4. Construir la imagen: En PowerShell o CMD, entra a la carpeta del proyecto y ejecuta:

    docker build -t mi-web-html .

    Esto descargará la imagen base nginx:alpine (si no está localmente) y generará la imagen personalizada.

  5. Ejecutar el contenedor: Publica el puerto 80 del contenedor al puerto 8080 del host con el comando:

    docker run -d -p 8080:80 --name mi-web-container mi-web-html

    Abre el navegador en http://localhost:8080 para ver la página servida desde el contenedor.

Demostración

Comandos Principales de Docker

  • docker --version: Consultar la versión instalada de Docker.

  • docker run hello-world: Ejecutar una imagen de prueba básica.

  • docker images: Listar las imágenes locales descargadas o creadas.

  • docker ps: Mostrar los contenedores que están corriendo en este momento.

  • docker ps -a: Mostrar todos los contenedores (tanto activos como apagados).

  • docker build: Construir una imagen a partir de un archivo Dockerfile.

  • docker run: Crear y ejecutar un contenedor nuevo.

  • docker stop: Detener un contenedor que está en ejecución.

  • docker start: Iniciar un contenedor que estaba detenido.

  • docker rm: Eliminar un contenedor detenido.

  • docker rmi: Eliminar una imagen del sistema.

  • docker logs: Consultar los registros o salidas de consola de un contenedor.

  • docker exec: Ejecutar comandos dentro de un contenedor en ejecución.
