Tutorial: Primer Contenedor Web con Docker y Nginx

Aprende a empaquetar, configurar y desplegar una aplicación web estática dentro de un contenedor Nginx optimizado utilizando Docker[cite: 9].

Paso a paso para crear y desplegar

Guía práctica por Batallón Fantasma 404[cite: 9]

  1. Crear la carpeta de trabajo

    Crea el directorio de trabajo donde residirán tus archivos de configuración, por ejemplo: C:\docker-lab-web[cite: 9].

  2. Crear el archivo index.html

    Dentro de la carpeta, crea el archivo HTML base que servirá el contenedor[cite: 9].

  3. Crear el archivo Dockerfile

    En la misma raíz del directorio, crea un archivo nombrado exactamente como Dockerfile (sin extensión) con la configuración para Nginx[cite: 9].

  4. Construir la imagen personalizada

    Abre una terminal (PowerShell o CMD), navega a la carpeta del proyecto y ejecuta[cite: 9]:

    docker build -t mi-web-html .

    Esto descargará la imagen base nginx:alpine (si no existe localmente) y generará tu imagen personalizada[cite: 9].

  5. Ejecutar el contenedor

    Publica el puerto 80 del contenedor en el puerto 8080 de tu máquina anfitriona[cite: 9]:

    docker run -d -p 8080:80 --name mi-web-container mi-web-html

    Abre tu navegador e ingresa a http://localhost:8080 para comprobar que la página está activa desde Docker[cite: 9].

Comandos Principales de Docker

Referencia rápida de los comandos esenciales para administración de imágenes y contenedores[cite: 9]:

Comando Descripción
docker --version Consultar la versión instalada de Docker[cite: 9].
docker run hello-world Ejecutar una imagen de prueba básica[cite: 9].
docker images Listar las imágenes locales descargadas o creadas[cite: 9].
docker ps Mostrar los contenedores que están corriendo actualmente[cite: 9].
docker ps -a Mostrar todos los contenedores (activos y detenidos)[cite: 9].
docker build -t <nombre> . Construir una imagen a partir de un archivo Dockerfile[cite: 9].
docker run <opciones> <imagen> Crear y ejecutar un contenedor nuevo[cite: 9].
docker stop <id/nombre> Detener un contenedor en ejecución[cite: 9].
docker start <id/nombre> Iniciar un contenedor que estaba detenido[cite: 9].
docker rm <id/nombre> Eliminar un contenedor detenido[cite: 9].
docker rmi <imagen> Eliminar una imagen local del sistema[cite: 9].
docker logs <id/nombre> Consultar registros o salidas de consola de un contenedor[cite: 9].
docker exec -it <id/nombre> sh Ejecutar comandos interactivos dentro de un contenedor[cite: 9].
