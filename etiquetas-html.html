Etiquetas HTML de Uso Común

Texto y Enlaces

  • <h1> a <h6>: Definen títulos. Es apropiado usar h1 para el título principal y los demás para subtítulos.
    Ejemplo en el sitio: <h1 class="display-4"> en la portada.
  • <p>: Define párrafos de texto. Usar siempre para bloques de lectura.
    Ejemplo en el sitio: Descripciones de los integrantes.
  • <a>: Crea hipervínculos. Apropiado para conectar páginas.
    Ejemplo en el sitio: <a href="index.html"> en el menú.

Multimedia y Listas

  • <img>: Inserta imágenes. Apropiado para recursos visuales estáticos.
    Ejemplo en el sitio: <img src="img/pjw.jpg"> en las tarjetas de perfil.
  • <ul> y <ol>: Listas desordenadas (viñetas) y ordenadas (números). Usar para agrupar ítems relacionados.
  • <li>: Define cada ítem de una lista.
    Ejemplo en el sitio: Usado en listas de habilidades tecnológicas.

Contenedores Estructurales

  • <div>: Contenedor genérico a nivel de bloque. Usar para agrupar elementos y aplicar estilos CSS o grillas.
    Ejemplo en el sitio: <div class="row"> de Bootstrap.
  • <span>: Contenedor genérico en línea. Apropiado para dar estilo a una parte específica de un texto.
    Ejemplo en el sitio: Aplicar un color específico a una palabra clave.

Tablas y Formularios

  • <table>: Muestra datos tabulares.
    Ejemplo en el sitio: Usado en la página "HTML semántico" para comparar etiquetas.
  • <form>, <label>, <input>, <button>: Elementos para recibir datos del usuario. form agrupa, label describe, input recibe y button envía.
    Ejemplo de aplicación: Creados para una sección simulada de "Contacto" en los portafolios individuales.
