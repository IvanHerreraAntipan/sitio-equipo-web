Etiquetas Semánticas de HTML

El HTML semántico permite que el código sea comprensible tanto para los desarrolladores como para los navegadores, definiendo claramente la estructura y propósito del contenido.

Propósito y aplicación en el sitio

Etiqueta Propósito Uso en nuestro sitio
<header> Define la cabecera de una página o sección, usualmente contiene navegación o logos. Utilizada en la plantilla base para envolver la sección superior de navegación.
<nav> Define una sección de enlaces de navegación principales. Utilizada dentro del contenedor .nav-custom-bar para el menú superior de todas las páginas.
<main> Especifica el contenido principal y único del documento. Envuelve el contenido central de esta y todas las páginas del proyecto.
<section> Define una sección genérica agrupada por un tema. Utilizada en las páginas de perfiles individuales para dividir habilidades y proyectos.
<article> Representa un contenido independiente y autónomo que tiene sentido por sí solo. Se utiliza en pagina.html para estructurar las entradas de texto simuladas.
<aside> Contiene información tangencialmente relacionada con el contenido principal. Empleada en las barras laterales de la estructura base del blog para mostrar enlaces adicionales.
<footer> Define el pie de página de un documento o sección. Ubicada al final de la página principal para mostrar los derechos de autor del equipo.

Ejemplo de código implementado

<!-- Estructura semántica típica utilizada en nuestro proyecto -->
<header>
    <nav>
        <!-- Menú de navegación -->
    </nav>
</header>

<main>
    <section>
        <h1>Tema Principal</h1>
        <article>
            <p>Contenido específico y autónomo.</p>
        </article>
    </section>
    
    <aside>
        <!-- Enlaces o contenido secundario -->
    </aside>
</main>

<footer>
    <p>&copy; 2026 Batallón Fantasma 404</p>
</footer>
