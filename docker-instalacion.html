Tutorial: Instalar Docker en Windows

¿Qué es Docker Desktop?

Docker Desktop es una aplicación para entornos Windows que permite crear, depurar y ejecutar aplicaciones contenedorizadas de manera local, integrando el motor de Docker y soporte para WSL 2.

Requisitos básicos:

  • Windows 10/11 de 64 bits con WSL 2.
  • Virtualización habilitada en el BIOS/UEFI.
  • Mínimo 4 GB de memoria RAM.

1. Descargar Docker Desktop

  • Abrir el navegador y entrar a: Docker Desktop
  • Buscar el botón “Download Docker Desktop” y descargar el instalador para tu sistema operativo.

2. Instalar Docker Desktop

  • Ejecutar el instalador Docker Desktop Installer.exe.
  • En el asistente de instalación, aceptar los términos y mantener la opción por defecto de usar WSL 2 (si aparece).
  • Pulsar Next / Install hasta finalizar.
  • Al terminar, pulsar Close y reiniciar el equipo si el instalador lo solicita.

3. Primer arranque y prueba rápida

  1. Abrir Docker Desktop desde el menú Inicio y esperar hasta que el estado cambie a Running (ícono de la ballena activa en la bandeja del sistema).

  2. Abrir la Terminal o PowerShell y ejecutar el comando: docker run hello-world
