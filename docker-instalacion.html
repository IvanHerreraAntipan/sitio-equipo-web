¿Qué es Docker Desktop?

Fase de entorno por Batallón Fantasma 404[cite: 9]

Docker Desktop es una aplicación para entornos Windows que permite crear, depurar y ejecutar aplicaciones contenedorizadas de manera local, integrando el motor de Docker y soporte para WSL 2[cite: 9].

Requisitos básicos del sistema:

  • Windows 10/11 de 64 bits con WSL 2[cite: 9].
  • Virtualización habilitada en el BIOS/UEFI[cite: 9].
  • Mínimo 4 GB de memoria RAM[cite: 9].

1. Descargar Docker Desktop

  • Abrir el navegador y acceder al portal oficial: Docker Desktop Official[cite: 9]
  • Buscar el botón “Download Docker Desktop” y descargar el instalador para Windows[cite: 9].

2. Instalar Docker Desktop

  • Ejecutar el archivo instalador: Docker Desktop Installer.exe[cite: 9].
  • En el asistente de instalación, aceptar los términos y mantener la opción por defecto de usar WSL 2[cite: 9].
  • Pulsar Next / Install hasta finalizar el proceso[cite: 9].
  • Al terminar, pulsar Close y reiniciar el equipo si el instalador lo solicita[cite: 9].

3. Primer arranque y prueba rápida

  1. Abrir Docker Desktop desde el menú Inicio y esperar hasta que el estado cambie a Running (ícono de la ballena activo en la bandeja del sistema)[cite: 9].
  2. Abrir la Terminal o PowerShell y ejecutar el comando de verificación: 
    docker run hello-world

Sobre este módulo

La instalación adecuada de Docker Desktop junto con WSL 2 es el paso previo necesario para poder construir imágenes personalizadas y desplegar servicios web locales[cite: 9].
