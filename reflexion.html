Reflexión y Conclusiones del Proyecto

Balance del trabajo colaborativo, metodología aplicada, retos superados y aprendizajes adquiridos por el equipo Batallón Fantasma 404.

Metodología de Trabajo y Planificación

Para este proyecto, el plan inicial consistió en construir primero la página principal y definir una plantilla base compartida. La idea era establecer fechas límite claras para que todo el equipo tuviera la misma estructura de diseño antes de que cada integrante comenzara a desarrollar sus respectivas secciones.

Esto permitió tener una guía visual clara sobre cómo debían organizarse los componentes, la navegación y los estilos generales del sitio.

Retos en el Flujo de Git y Organización

A pesar de los acuerdos previos, enfrentamos algunos contratiempos durante el desarrollo:

  • Desviaciones de la plantilla: Algunos compañeros avanzaron con código propio sin usar la plantilla base acordada, lo que obligó a realizar ajustes posteriores para unificar el diseño.
  • Uso incorrecto de ramas: Aunque se definió que cada integrante debía trabajar en su propia sub-rama, se realizaron cambios directos en la rama principal (main), una práctica que debimos corregir para evitar sobrescribir código de otros.

Identidad Visual y Gestión de Recursos

En cuanto a la presentación del equipo, no se logró un consenso a tiempo para utilizar un estilo único de avatar o fotografía para todos los perfiles.

Debido a los plazos de entrega, se tomó la decisión práctica de conservar las imágenes en el formato original en que fueron enviadas por cada integrante, adaptándolas mediante estilos y contenedores para mantener la armonía visual sin retrasar la entrega final.

Aprendizajes Clave del Equipo

Este trabajo nos dejó valiosas lecciones para futuros proyectos de desarrollo colaborativo:

  • Importancia de la comunicación: Mantener una coordinación constante evita retrabajos al integrar las diferentes partes.
  • Disciplina con Git: Respetar el flujo de trabajo en ramas independientes protege la estabilidad del proyecto.
  • Adaptabilidad y resolución: Logramos resolver las discrepancias de código y entregar una plataforma sólida, funcional y coherente.
