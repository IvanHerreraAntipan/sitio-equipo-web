¿Por qué usar Docker en Desarrollo Web?

Módulo de Infraestructura · Batallón Fantasma 404

En el desarrollo tradicional, es común el problema de "en mi máquina funciona" debido a diferencias en versiones de software, librerías del sistema operativo o configuraciones del servidor.

Docker soluciona esto aislando la aplicación junto con todas sus dependencias dentro de una unidad estandarizada llamada contenedor. A diferencia de una máquina virtual pesada que virtualiza todo el sistema operativo con su propio kernel, los contenedores comparten el kernel del anfitrión, haciéndolos ultraligeros y rápidos de iniciar.

"Un contenedor empaqueta el código fuente, el servidor web y los archivos estáticos en una imagen inmutable lista para ejecutarse en cualquier entorno."

¿Qué es Nginx y cuál es su función?

Nginx (pronunciado engine-x) es un servidor web asíncrono y de alto rendimiento. En nuestra arquitectura, cumple dos tareas clave:

  • Servidor de archivos estáticos: Despacha con mínima latencia documentos HTML, hojas de estilo CSS, scripts e imágenes.
  • Mapeo de red: Expone el puerto interno del contenedor hacia el puerto del anfitrión para que cualquier usuario acceda mediante su navegador web.

La Imagen Base: nginx:alpine

Para nuestro despliegue utilizamos la variante Alpine Linux de Nginx. Esta distribución reduce el peso total de la imagen a menos de 30 MB, optimizando tiempos de descarga y minimizando la superficie de vulnerabilidades de seguridad.
